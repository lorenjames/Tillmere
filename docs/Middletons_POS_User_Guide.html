Navigation and Basics

  1. Use the top bar to switch between POS, Receipts, and Reports.
  2. Select the hamburger menu (Configuration) for setup tasks: Vendors, Cashiers, Schedule, Gift Cards, Opening and Closing, Settings, User Guide, and Close App.
  3. If you try to leave POS with items in the cart, confirm the warning to avoid losing a sale.
  4. Use Clear buttons in filters to reset a screen quickly.

POS (Sales)

Start a sale

  1. Select Cashier from the dropdown.
  2. Select Payment type: Cash, Card, Check, or Gift Card.
  3. Optional: enable Back-date sale and select a Sale Date.
  4. Optional: enable No Tax and enter purchaser name and tax ID in the modal.
  5. Optional: enable Split tender if two payment types are used.

Add items

  1. Enter Item name.
  2. Enter Price and Qty (use the picker for common quantities).
  3. Enter Vendor name or code and pick from suggestions.
  4. Optional: choose a Discount type, enter Value, and select a Reason.
  5. Optional: add a Comment for notes like condition.
  6. Click Add Item to place it in the cart.

Review and adjust

  1. Review Subtotal, Tax, and Total as they update.
  2. Edit or remove any line item from the cart table.
  3. For Cash: enter Cash Received and confirm Change Due.
  4. For Gift Card payments: enter the card number and redeem amount.
  5. For Split tender: select the second payment type and amount.

Finish the sale

  1. Click Print and Save to record the sale.
  2. Print the receipt or allow silent printing if enabled.
  3. The cart clears after printing.
  4. If a gift card was sold, open Gift Cards to activate it.
Gift card reminder: after a sale with gift cards, you are prompted to activate them on the Gift Cards page.

Receipts

Search and filter

  1. Enter a search term (receipt number, item, vendor, cashier).
  2. Set From and To dates if needed.
  3. Choose Cashier, Payment, and Void filters.
  4. Click Apply. Use Clear Filters to reset.

View or print

  1. Click View to open a receipt preview.
  2. Click Print to print another copy.

Void a receipt

  1. Click Void on the receipt row.
  2. Select the cashier and enter a reason.
  3. Confirm to mark the receipt as voided.

Record a return

  1. Click Return on a receipt.
  2. Choose Entire Receipt or select specific items.
  3. Enter a reason and confirm.

Reports

Sales per Vendor

  1. Set From and To dates.
  2. Optionally choose a Vendor.
  3. Click Run Report.
  4. Use Export CSV to save a spreadsheet.
  5. Use Print for summary or Print Detailed for per-vendor detail.

Credit card fee summary

  1. Review the 5 percent fee table after running a report.
  2. Use it for reference when settling vendor fees.

Tax Exempt Sales (Manager Mode)

  1. Enable Manager Mode in Settings.
  2. Set the date range and click Run.
  3. Export or Print as needed.

Backup and Restore (Developer Mode)

  1. Enable Developer Mode in Settings.
  2. Use Backup Data to save a full JSON file.
  3. Use Restore Data to load a previous backup (replaces current data).

Gift Cards

Create a book

  1. Enter an optional Book Label.
  2. Enter Prefix (example: GC-).
  3. Set Pad Length if you want zero-padding.
  4. Enter Start and End numbers.
  5. Click Add Book to generate cards.

Activate a card

  1. Find the card in the Available list and click Activate.
  2. Enter Amount, Cashier, optional Receipt, and Note.
  3. Click Activate to move it to Active status.

Lookup balance

  1. Enter the Gift Card number in Lookup Balance.
  2. Click Lookup to see balance and history.

Inventory overview

  1. Review Available, Active, and Redeemed counts.
  2. Use the book summary to see remaining cards by book.

Opening and Closing (Cash Drawer)

Opening

  1. Click Opening.
  2. Select the cashier.
  3. Enter counts for each denomination.
  4. Click Submit Opening.
  5. If prompted, add a note explaining changes.

Closing

  1. Click Closing.
  2. Select the cashier and enter counts.
  3. Review the deposit amount shown.
  4. Click Submit Closing.

Verify deposit

  1. Confirm the deposit totals.
  2. Enter the deposit number.
  3. Click Confirm Deposit.

Submit daily totals

  1. Click Submit Daily Totals.
  2. Review closing totals, deposit amount, and notes.
  3. Click Verify and Submit.

Schedule

Week view

  1. Use Prev Week or Next Week to navigate.
  2. Assign cashiers to shifts for each day.

Monthly coverage

  1. Review the monthly calendar summary.
  2. Click Print Calendar to print.

Configure hours

  1. Click Configure Hours.
  2. Add or edit Base Shifts.
  3. Set Store Hours for each day.
  4. Add Special Hours for holidays or exceptions.
  5. Save Configuration.

Vendors

  1. Open Configuration and choose Manage Vendors.
  2. Enter vendor name and optional code.
  3. Click Add Vendor.
  4. Edit or delete a vendor using the actions in the list.

Cashiers

  1. Open Configuration and choose Manage Cashiers.
  2. Enter the cashier name.
  3. Click Add Cashier.
  4. Edit or remove a cashier from the list.

Settings

Enable Manager Mode

  1. Click Enable Manager Mode.
  2. Enter the manager password.
  3. Manager-only sections become visible.

Sales Tax and Gift Card Surcharge

  1. Enter the Tax Rate percent and click Save.
  2. Enter the Gift Card Surcharge percent and click Save.

Denomination Targets

  1. Enter target counts for each denomination.
  2. Click Save Denomination Targets.

Discount Reasons

  1. Edit the reasons list (one per line).
  2. Click Save Reasons.

Vendor Promotions

  1. Click Manage to add promotions.
  2. Choose vendor, discount type and value, and dates.
  3. Add, edit, or delete promotions as needed.

Developer Mode

  1. Click Enable Developer Mode.
  2. Use it only when a manager or support requests it.

Passwords

  1. Click Change Passwords.
  2. Enter current and new passwords, then Save.

Printing

  1. Enable Silent Print to send receipts directly to a printer.
  2. Select a specific printer or leave System Default.
  3. Enable Greyscale to force black and white receipts.
  4. Click Save.

Branding

  1. Enter business name, address, and phone.
  2. Upload a logo if desired.
  3. Click Save Branding.

Backups

Automatic

  1. Automatic backups run when the app closes.
  2. Keep manual backups in a separate folder for safety.

Manual backup

  1. Enable Developer Mode in Settings.
  2. Open Reports and click Backup Data.
  3. Choose a folder and filename.

Restore

  1. Enable Developer Mode in Settings.
  2. Open Reports and click Restore Data.
  3. Select the backup file and confirm.

Close App

  1. Open the hamburger menu (Configuration).
  2. Click Close App.
  3. The app closes and performs an automatic backup.

Troubleshooting and Tips

  1. If printing fails, confirm the printer selection in Settings and retry Print and Save.
  2. For tax exempt sales, always enter purchaser name and tax ID.
  3. Use manual backups regularly for extra safety.
  4. If data looks incorrect, stop and consult a manager before restoring a backup.
  5. For web deployments, verify `.env` includes `MIDDLETONS_API_BASE` and `MIDDLETONS_DATA_DIR`.
